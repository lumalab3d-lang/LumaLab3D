    Copia de seguridad

    Guarda de vez en cuando un archivo con todos tus datos (impresoras, insumos, productos y ventas). Si algo llegara a borrarse del navegador, lo restauras desde ese archivo.

    En el iPad, «Descargar copia de seguridad» te deja guardar el archivo en la app Archivos — así tienes un respaldo fuera del navegador.

    Camino hacia web multi-dispositivo

    Hoy todo vive en la memoria de este navegador. Así se vería crecer la app cuando quieran compartirla entre varios dispositivos o publicar el stock.

    Fase actual

    • App de una sola página, sin cuenta ni internet necesario. Funciona en el iPad agregándola a la pantalla de inicio desde Safari (ícono compartir → «Agregar a pantalla de inicio»).

    Fase 2 — Base de datos

    • Se conecta a una base de datos (por ejemplo Supabase o Firebase) para que impresoras, insumos, productos y ventas se guarden en la nube.
    • Ahí sí conviene desplegar en Vercel: aloja el sitio gratis y lo conecta con la base de datos.

    Fase 3 — Multi-dispositivo y tienda pública

    • Con cuenta de usuario, el mismo inventario se ve igual en el iPad, el teléfono y la computadora.
    • Una página pública lista el stock disponible con fotos y precios para que la gente vea qué hay para comprar.
